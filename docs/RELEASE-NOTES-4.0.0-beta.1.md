# SS本地模型管理器 4.0.0-beta.1

这是首个 Windows x64 **CPU 测试安装包**，不是完整 GPU 正式版。

下载安装 SSLocalModelManager-4.0.0-beta.1-win-x64-Setup.exe，确认位置后点击“一键安装”。不需要 Python、Git、开发 SDK 或 AI 协助；安装包不包含大模型。需要 Windows 11 x64、AVX2 CPU 和足够内存。

本批验证：123项核心检查、真实静默安装、Qwen3-0.6B Q8_0 对话与流式、真实CPU KV分配、5页面及4监控子页、无效/忙碌切换保护、空闲切换、重启、卸载保留外部模型和配置。具体提交和产物哈希见 verification.json 与 SHA256SUMS.txt。

4K上下文测试组合的CPU KV分配为448 MiB；该值不是所有模型的固定推荐值，也不是动态已用字节。

**当前限制：** Strata、CUDA/GPU加速、视觉、完整自动调优/习惯学习、覆盖升级和代码签名尚未完成；调优参考数据库尚未接到参数页，建议显示待评估。NVIDIA监控与功率能力不在本批跨设备验收承诺中，不会自动调功率。不能视为原完整方案已全部交付。

已有测试版请先正常卸载程序再安装；外部模型和用户数据保留。安装目标应为空目录，不要使用模型权重目录。

仅修改独立发行工程，不替换作者现用模型控制台。第三方许可随包保留，测试权重不随包发布。
