# SS本地模型管理器

Windows 本地模型管理、运行监控与参数配置工具。采用深浅主题、中英文切换和彩色仪表界面，面向无需 AI 协助安装的桌面使用场景。

> **当前状态：4.0.0-beta.1 正在构建和整合验收，安装包尚未发布。**  
> 请以 [Releases](https://github.com/sooyings/ss-local-model-manager/releases) 中实际存在的附件为准；不要将源代码 ZIP 当作安装包。

## 功能与当前范围

- 模型库：只读发现 GGUF，检查文件头与分片完整性，原地引用已有权重；支持模型分页与显示名修改。
- 界面：总览、模型库、监控、接口和运行参数；深浅主题、中英文与等比缩放。
- 运行隔离：独立数据目录、单实例标识和默认端口，按真实进程身份管理自己启动的服务。
- 请求保护：本地请求代理、流式响应及忙时拒绝停止；不会按端口或同名进程结束其他软件的模型。
- 参数：白名单、范围检查、配置指纹与备份；建议值和当前值分开。
- 调优种子：5个模型、40项参考字段，区分作者建议、单机基线和规则推导。未知或未验证组合显示待评估，不冒称最优。
- 安装：用户级安装内核、实际进度事件、无人值守接口和保留模型数据的卸载策略。

目前受管推理后端正在验证 CPU llama.cpp 路径。Strata、GPU加速、视觉、完整自动调优和跨硬件功率能力需逐项验收，尚不能视为全部可用。相关限制会随实际构建结果更新。

## 下载与安装

发行后按以下方式使用：

1. 在 [Releases](https://github.com/sooyings/ss-local-model-manager/releases) 下载与 Windows x64 对应的 `SSLocalModelManager-…-Setup-win-x64.exe`。
2. 双击安装包，确认安装目录和安装说明，点击“一键安装”。
3. 等待进度与结果确认；安装完成后打开管理器。
4. 使用模型库的“扫描”或“导入”，登记已有 GGUF。分片模型请选择第一片，所有分片须齐全。
5. 根据模型支持状态启动。没有模型或运行验证未完成时，程序会明确提示，不会自动下载几十 GB 权重。

自包含发行物的目标是不要求用户另装 Python、Git、开发 SDK 或 AI 工具。具体系统要求、验证过的引擎和已知限制以对应 Release 说明为准。

### 无人值守安装

以下是正在验证的命令接口，正式可用性以发行说明为准：

```powershell
.\SSLocalModelManager-Setup.exe --unattended --accept-license --dir "D:\Apps\SSLocalModelManager" --report "D:\install-result.json"
```

安装目标须为空的可写目录。升级和修复机制尚在整合，暂不覆盖已有安装目录。安装结果文件区分程序安装状态与模型验证状态。

## 数据与安全

- 已有模型保持原位置，登记不代表软件拥有其删除权。
- 程序数据与模型权重分开；卸载默认保留用户数据和外部模型。
- 发布开发使用独立工作区，不覆盖作者正在使用的本地模型控制台。
- 不读取聊天正文、知识库、账号密钥；不提供默认云端兜底。
- 未提供的监控指标显示未知，不用 token、显存或容量冒充动态 KV 使用量。
- 显卡功率操作须独立验证设备能力并显式应用，安装或模型切换不会自动改功率。
